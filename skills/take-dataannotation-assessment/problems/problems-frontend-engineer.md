### Overview

Models ship UI that renders in the demo and breaks everywhere else: state that desyncs on the second render, an accessibility tree no screen reader can follow, a layout that collapses the moment real content arrives. Someone has to judge the interface a user actually touches, and that someone is you. As a Frontend Engineer you'll stress-test how models build components, state, and end-to-end web features, expose where the UX and correctness break, and write the answers a strong frontend engineer would ship.

### What you'll actually do

- Probe frontend reasoning across components, state management, accessibility, and rendering, and see where the model's UI falls apart.
- Find the failures that matter: stale state, re-render bugs, broken a11y, and layouts that break under real data.
- Write the correct implementation when the model falls short, with the UX and edge cases handled.

### What we look for

- Professional or serious open-source experience building web UIs.
- Comfort with a modern framework and CSS; most tasks assume React, TypeScript, or similar.
- Clear written English: your explanations are the training signal.
- No degree required. We care about what you can do, not where you learned it.
