### Overview

Models can scaffold a whole app in one shot: front end, API, and database, all of it looking right. Then the state goes stale, the endpoint leaks data, and the migration breaks production. Someone has to trace a feature across every layer and find where it actually breaks, and that someone is you. As a Full Stack Engineer you'll run frontier models on real end-to-end tasks, analyze what they build across the stack, and write the judgments that teach the next generation to ship features that hold together.

### What you'll actually do

- Build with frontier models on real end-to-end tasks: wire a UI to an API, model the data, and see how far the model gets.
- Trace the feature across layers to find where it breaks: stale state, leaky endpoints, and migrations that don't survive contact with real data.
- Write the working version when the model falls short, sound from the component down to the schema.

### What we look for

- Professional or serious open-source experience shipping full-stack applications.
- Comfort across the stack; most tasks span a JavaScript front end, an API layer, and a database.
- Clear written English: your explanations are the training signal.
- No degree required. We care about what you can do, not where you learned it.
