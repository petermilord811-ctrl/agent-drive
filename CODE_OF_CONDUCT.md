# Code of conduct

This project follows the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**.
In short:

- Be respectful and welcoming, whatever someone's experience, background or identity.
- Give and take criticism about the work, not the person; assume good faith.
- No harassment, insults, personal attacks, or publishing anyone's private information.
- And, because this kit operates other people's computers: never use it — or ask others to use it — on a
  machine without its owner's consent.

Maintainers may remove, edit or reject contributions, comments, issues and pull requests that do not follow
this code, and may ban contributors for behaviour they judge harmful.

**Reporting:** contact the maintainers privately through GitHub (a direct message to a maintainer listed in
`.github/CODEOWNERS`). Reports are handled confidentially.
